Modal

Use a modal for a focused task that temporarily blocks the rest of the page, such as editing a ticket holder’s name.

API reference ↓

Usage

Import the dialog parts and put the trigger and panel inside Dialog.

import {
  Dialog, DialogTrigger, DialogContent,
  DialogTitle, DialogDescription,
} from "@/components/ui/dialog"
import { Button } from "@/components/ui/button"

<Dialog>
  <DialogTrigger asChild><Button>Review ticket</Button></DialogTrigger>
  <DialogContent>
    <DialogTitle>Review your ticket</DialogTitle>
    <DialogDescription>Check the name before you continue.</DialogDescription>
  </DialogContent>
</Dialog>

Anatomy

  1. Trigger. The button that opens the modal and receives focus when it closes.
  2. Header. Use DialogHeader to group the title and optional icon.
  3. Body. Use DialogBody for independently scrollable content.
  4. Footer. Use DialogFooter for the actions that finish or cancel the task.

Accessibility

Give every modal a descriptive title. Tab stays inside a modal while it is open. Escape closes it by default. If you disable Escape or backdrop dismissal, provide an explicit close or cancel action.
