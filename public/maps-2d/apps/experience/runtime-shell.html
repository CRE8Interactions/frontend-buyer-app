3D DECK SETTINGS

Rise and slope

Legacy deck_*rise*_rake* layer names are read once during SVG import and stored in project JSON. Studio edits that JSON, which then drives Player and Admin previews.

SVG naming guide
surface_type_icePlaying surface; replace ice with the surface name.baseGroup containing the base geometry.element_wrapperOuter bowl boundary inside base; Wrapper is also accepted.shapeAdditional base shell shape.elevation_lineOrigin from which rake height is measured. Numbered names such as elevation_line_2 work too.deck_2rise12_rake18Deck 2, vertical rise 12, rake angle 18°. Decimal numbers are accepted.sec-109Section group. Seats use sec-109-row-A-seat-1.*_height6Adds a fixed height of 6 to that section.box_name_height20Fixed-height architectural block.NZ_benchMarks a sec-* group as a GA bench section.bench_*Authored bench path inside an NZ_bench section.DAMarks an accessible seat.

Decks use elevation_line by default. Set data-elevation-line when a deck needs another reference.
